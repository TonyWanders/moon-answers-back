A program that writes one line in the voice of the Moon answering back to `/output/entry.txt`, for the make.fun competition [The Moon Finally Answers Back](https://make.fun/bounty/u-mang-the-moon-finally-answers-back-781a7ec1).

Run it with Python 3:

```
python3 main.py
```

It writes the entry below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The entry is 99 characters, inside the 1 to 240 gate.

## The entry

```
I heard every wish. I granted none of them. I am a rock with good lighting and no customer service.
```
